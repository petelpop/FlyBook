# FlyBook
I developed an application to improve my skills in state management using Cubit. Through this project, I also enhanced my understanding of Firebase, particularly in using Firestore and implementing authentication features.

The application serves as a prototype for an airplane ticket booking system, simulating core functionalities such as user login, data storage, and state management for a seamless user experience. This project allowed me to apply what I learned and gain hands-on experience in building a scalable and interactive application using modern development practices.
